How to Use:

  • Click a cell to cycle through states: Empty → Soft Preference → Hard Preference → Empty
  • Drag to select a rectangle area and fill with the current drawing mode
  • Select a mode below to change what dragging does
  • M/T/W/R/F = Monday, Tuesday, Wednesday, Thursday, Friday
  • JSON output updates automatically with every change
